# DataForge — site de révision RNCP 37680

Site statique sans dépendance externe : `index.html`, `styles.css` et `app.js`.

## Contenu

- 12 fiches interactives couvrant le projet DataForge et le dossier professionnel ;
- QCM de 50 questions avec correction immédiate et score sauvegardé dans le navigateur ;
- 40 flashcards ;
- mode oral blanc avec réponse modèle et auto-évaluation ;
- affichage responsive téléphone/ordinateur.

Le site ne contient ni identifiant, ni mot de passe, ni clé, ni adresse personnelle. Les éléments de révision sont synthétisés à partir du projet ; les distinctions entre cible, preuve disponible et expérience NetStrategy sont volontairement conservées.

## Publication GitHub Pages

Publier le contenu de ce dossier sur la branche `main`, puis activer GitHub Pages avec la source « Deploy from a branch », branche `main`, dossier `/root`. Le fichier `index.html` est déjà à la racine du site.
